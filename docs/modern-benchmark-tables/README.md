# Modern benchmark publication tables

TSV files retain numeric precision; booktabs LaTeX files provide typeset tables. The `paper-*` tables use longtable and booktabs; bracketed ranges are observed minima and maxima. GENCODE and nascent reference panels are separate. Peak RSS is the maximum sequential stage peak. All reported triplicates require one warmup. See [results](../modern-benchmark-results.md) and [methods](../modern-benchmarks.md) for scope and interpretation.
