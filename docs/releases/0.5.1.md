# kallistors 0.5.1

## Changes

- Faster quantification through packed index loading, exact cached matching, direct buffered
  Rust `zlib-rs` gzip decoding and borrowed EC counting after fragment sampling. Integrity checks,
  candidate order, strand filtering and every counted EC remain covered by regressions.
- Lower quantification memory through compact metadata, shared worker EC keys, bounded read
  queues, deferred names and releasing graph storage before EM. Independent EM components run
  in parallel; dominant components also share ordered EC and transcript work across the same
  pool. Scheduling follows graph workload, preserving arithmetic order and convergence; only
  bitwise fixed work is skipped.
- Faster, smaller-memory index construction through byte-proven repeat-window exclusions,
  packed bounded collections, parallel radix sorting, batched exact edge probes and compact
  graph/EC scratch. Ordered graph claims, all minimizer ties and deterministic v13 output remain.
  Stage timers are exclusive and include final cleanup in the internal total. Exact graph bounds choose direct or
  global compact location storage, reducing large graph working memory while retaining the small graph path.
- Match upstream jump/midpoint advancement over ambiguous bases, preserving mature/nascent EC
  membership and paired alignment. Two real TT-seq pairs protect both scanners and one/eight threads.
- Fix paired strand filtering, reverse-unitig backoff confirmation and abundant-node key/EC
  associations. Preserve existing v13 index loading and kallisto-style output schemas.
- Match original paired fragment sampling: a 10,000-observation goal across 8 MiB combined
  sequence buffers, with possible concurrent overshoot. All reads contribute to EC counts.
  Use `--fragment-length-samples 0` to collect all qualifying observations; single-end runs use
  the supplied fragment model. See [sampling behavior](../fragment_length_sampling.md).
- Bound HDF5 chunks to 16,384 elements with DEFLATE level 1; preserve dataset names/types/shapes.
  Native HDF5 validates every retained current transcript row. TSV formatting remains ordered.
- Use pinned fastp 1.4.0 for new read preparation, with executable/input hashes and complete
  paired-read validation for single-cell libraries.
- Extend counting to ordinary stranded, compound-barcode, tagged and paired BUS input,
  and batch BAM records for ordered parallel mapping. Preserve complete paired BUS
  fragment histograms, tag precedence, ambiguity flags and read limits.
- Borrow ordinary stranded ECs through orientation filtering and use packed positional
  graph loading. Finish bias sampling without retaining unused per-read mapping metadata.
- Share position decoding between single-end fragment and strand filters when they address
  the same annotation block, preserving both predicates. Decode native singleton coordinates
  without transient one-element vectors or intermediate serialized bitmap buffers. Pack
  native singleton groups directly into lossless position storage. Small groups fit inline on
  64-bit targets after complete coordinate and strand bounds are checked; wider and repeated
  coordinates retain full-value fallbacks. Batch independent MPHF rank-word loads during
  parallel unitig counting with bounded scratch and unchanged scalar lookup results.
  Omit unused singleton-arena flags, combine header validation with coordinate bounds,
  and share exact forward/reverse minimizer initialization for 23-base read windows.
  Encoded rescue retains exact candidate order and special-marker fallbacks.
- Speed ordinary single-cDNA BUS counting with compact index loading, packed concurrent input,
  ordered mapping/output overlap and bounded full-query reuse across workers and lanes. Retain
  full-byte collision checks, borrowed EC lifetimes, extended-mode processing and exact read limits.
- Reject disjoint-hit empty ECs in BUS records and mapping counts; retain the diagnostic
  rejection state. Cover this with a compact two-transcript regression and real single-cell preflight.
- Split graph construction, index loading, fast matching, EM/model/bootstrap work and BUS
  configuration/input into private modules with stable public entry points. Share serial/batched
  single-end filtering; preserve scanner order, arithmetic and serialized layouts.
- Consolidate diagnostics, output modules, distinct regressions and reproducible benchmark tools.
  Current manifests cover GENCODE v50 ALL and genuine TT-seq reads against only the official
  Pachter Lab mature-plus-nascent reference. Documentation covers current behavior and reproducible measurements.
- Share bootstrap workers across samples and large components, including single samples.
  Reuse compact scalar IDs and exact sampling plans while preserving sample order, RNG state,
  ordered arithmetic, convergence and pruning. Bound serial inverse-CDF tables to 64 MiB.

## Build and API notes

Requires Rust 1.97 or newer. Source builds use `target-cpu=native`; current CI and release
binaries use `target-cpu=generic`. The measured Rust source build used Rust 1.99.0.
Workload-specific source-build timings do not predict every assay or generic prebuilt binaries.

`strength_reduce 0.2.4` supplies exact precomputed MPHF divisors. Rust callers with exhaustive
`PseudoalignOptions` literals must include `fragment_length_samples` and `match_cache_size`;
using `..PseudoalignOptions::default()` selects the normal sampling goal and automatic cache budget.
Existing public entry points remain. See [cache sizing](../match-cache.md),
[compatibility limits](../compatibility.md) and the [development guide](../development.md).
